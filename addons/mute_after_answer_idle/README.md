# Review Time Bank Mute v10

Anki 25.09.2向けアドオンです。

## 主な動作

- Anki起動時の持ち時間は0秒です。
- 起動後、最初の対象カード表示時にフラグ時間の1.5倍を加算します。
- レビュー画面を開いている間だけ持ち時間が減少します。
- 新規カードおよび紫フラグのカード表示中は、持ち時間を減らしません。
- カード回答時とレビュー画面からの「期日を変更」成功時に、フラグ時間を加算します。
- Againでは追加で20秒を加算します。
- 紫フラグは停止・加算なしです。
- 0秒になるとPCをミュートし、Ankiをフルスクリーンにします。
- 時間が復活するかレビュー画面を離れると、アドオンが変更したミュートと画面状態を戻します。
- 回答を取り消すと、その回答で実際に加算された時間を戻します。

## フラグなしカードの自動分類

フラグなしカードを回答する瞬間に、カード表示開始からの実経過時間を取得します。
現在の設定秒数のうち、その経過時間より長い最小の時間に対応するフラグを自動付与します。

初期設定では以下のように分類されます。

- 20秒未満: 水色
- 20秒以上30秒未満: ピンク
- 30秒以上40秒未満: 青
- 40秒以上60秒未満: 緑
- 60秒以上90秒未満: オレンジ
- 90秒以上: 赤

120秒以上の場合も最大設定の赤になります。紫は自動付与の対象外です。
自動フラグは回答処理と同じUndoに含まれるため、回答を取り消すと元のフラグなしへ戻ります。

## 画面表示

- 下部レビューバー付近に持ち時間を表示します。
- メインレビュー画面右上のフラグアイコン横に追加秒数を表示します。
- フラグなしの場合は、現在の経過時間から自動付与予定の色と秒数を表示します。

## 初期フラグ時間

- フラグなし: 10秒
- 赤: 120秒
- オレンジ: 90秒
- 緑: 60秒
- 青: 40秒
- ピンク: 30秒
- 水色: 20秒
- 紫: 0秒（停止・加算なし）

設定は Anki の「ツール → アドオン → Review Time Bank Mute → 設定」から変更できます。
