# Add [[n: ... ]] Editor Button (v4)

- 選択テキストが消えてしまう問題を修正しました。
- `Editor.wrap` が無い環境では JS フォールバックで **選択文字列を保持したまま** `[[n: ... ]]` に置換します。
- ショートカットキーをアドオン設定から変更できるようにしました。

## ショートカットキー設定

Anki の「ツール」→「アドオン」→ 本アドオン →「設定(Config)」で `shortcut` を変更してください。

- 例: `"Ctrl+Alt+N"`（デフォルト）
- 無効化: `""` または `"disabled"` / `"off"` / `"none"`

※ ショートカット文字列は Anki / Qt の形式に従います（例: `Ctrl+Shift+N`, `Alt+N` など）。
