
# 期日プリセット（レビュー画面・8ボタン）

レビュー画面の **その他（More）** に、期日をワンクリックで設定できるボタンを **8個** 追加します。  
押下後は期日が変更され、**自動で次のカードに進みます**（標準の「期日を設定…」と同等）。

- 24.06/24.11 互換（新API / QueryOp フォールバック）
- `config.json` で 8 個のラベル・期日文字列を編集可能。指定数が 8 未満なら `4!` で補完、超過なら先頭 8 件のみ使用。

## config.json の例
```json
{
  "buttons": [
    {"label": "期日を 4! に設定", "due": "4!"},
    {"label": "期日を 7! に設定", "due": "7!"},
    {"label": "期日を 10! に設定", "due": "10!"},
    {"label": "今日にする (0!)", "due": "0!"},
    {"label": "明日にする (1!)", "due": "1!"},
    {"label": "2週間後 (14!)", "due": "14!"},
    {"label": "3週間後 (21!)", "due": "21!"},
    {"label": "1か月後 (30!)", "due": "30!"}
  ],
  "add_separator": true
}
```
