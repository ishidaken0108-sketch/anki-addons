# New Cards Created Order

新規カードの導入順を作成日順にするAnkiアドオンです。

## 動作

- 新規カードの `due` 位置を並べ直します。
- 並び順は、ノート作成日時 → カードテンプレート番号 → カードIDです。
- 初期設定では、古い作成日のカードから導入されます。
- 起動時、同期後、デッキ一覧表示時に自動で実行されます。
- `ツール` → `新規カードを作成日順に並べ直す` から手動実行できます。

## 注意

Ankiのデッキオプションで新規カードの収集順・表示順がランダムになっている場合、ランダム表示が優先されます。
作成日順にしたいデッキでは、Anki側の新規カード収集順を「昇順位置」または位置順に従う設定にしてください。
