Enhanced Cloze Preview/Review Companion v15

このアドオンは Enhanced Cloze 本体ではありません。
Enhanced Cloze 2.1 v2 ノートタイプに対して、これまで追加した以下の機能だけを提供します。

- Preview / Review で Cloze の囲みを解除
- [[n: ... ]] の囲み解除
- 最後の Cloze が消えた <li> の自動削除
- Cloze 削除時にプレビューを再読込せずスクロールを維持
- 通常編集後の「最後に操作した Cloze の次」への復帰

Enhanced Cloze 本体のメニュー・設定・ノートタイプ更新処理は含めていません。
そのため、本体と併用しても Tools > Enhanced Cloze が二重登録されません。

重要:
旧 v13 は Enhanced Cloze 本体を丸ごと含んでいるため、v15 と同時に有効にしないでください。
