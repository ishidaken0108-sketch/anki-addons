# Review Word Capture for Enhanced Cloze

AnkiのReview画面で選択した単語・熟語・フレーズを、Enhanced Clozeの新規カードとして即時追加します。

## 対象

- Anki 25.09.x
- ノートタイプ: `Enhanced Cloze 2.1 v2`
- 追加フィールド: `Content`

## 設定

「ツール → アドオン」からこのアドオンを選択し、「設定」を開きます。

設定できる項目:

- 新規カードの保存先デッキ（コロンあり／なしを個別設定）
- 追加ショートカット（初期値: `Ctrl+Shift+W`）

ショートカットは設定保存後すぐに反映され、Ankiの再起動は不要です。

## 使い方

1. Review画面で追加したい文字列をマウス選択します。
2. 設定したショートカットを押します。
3. 成功すると `新規カード追加：...` と通知されます。

## Contentへの追加ルール

通常の選択文字列はそのまま追加します。

例:

```text
take over
```

`英単語・熟語:意味` または `英単語・熟語：意味` の形式なら、最初のコロンで分割して次の形に変換します。

選択:

```text
take over:引き継ぐ
```

Content:

```text
take over

{{c1::引き継ぐ}}
```

意味側にさらにコロンが含まれていても、最初のコロンだけを区切りとして使います。

## 動作

- 1単語限定の制約はありません。
- 単語、熟語、フレーズを追加できます。
- 元カード情報やタグは追加しません。
- ContentにClozeがない場合だけ、Enhanced Clozeのno-cloze/basic mode用に`Cloze99`を内部設定します。
- Review画面のHTMLやEnhanced Cloze本体は変更しません。
